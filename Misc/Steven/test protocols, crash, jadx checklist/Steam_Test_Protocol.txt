ROLES
  Device under test (DUT) : runs the Steam app with the Steam Guard authenticator.
      Emulator : Android26 (emulator-5556), friend's Steam account.
      Phone    : Xiaomi Mi Note 2 (2c3f64eb), my own Steam account.
  "Attacker" PC           : Chrome incognito on the PC, signing in to the SAME account
                            on store.steampowered.com / steamcommunity.com.
  Steam 3.10.14 on both (emulator x86_64, phone arm64-v8a).

TIME RULE
  Write the PC clock time (local, UTC-7), HH:MM:SS. The pull script records UTC
  and device time at every stage, so the two can be lined up later.

MARKERS
  Anything typed starts with a marker: STEAM01, STEAM02 ... Never reuse one.

SAFETY RULES (read before starting)
  1. The authenticator exists on ONE device only. NEVER clear Steam's data or
     uninstall Steam while the authenticator is on the DUT. Move it away first
     (stage E). Clearing first = authenticator lost = revocation code needed =
     15-day trade/market restriction.
  2. Revocation code (R....) is written down OFF the phone and OUT of this
     project folder. Never type it into these files, the report or screenshots.
  3. Steam stores the authenticator secrets in its app data. Record WHERE they
     are and HOW they are protected. Never copy the values into notes, the
     report, screenshots or GitHub. Keep collected\ off GitHub.
  4. Use only the two accounts named above, with their owners' consent.

PULL COMMANDS (project folder, PowerShell)
  Phone:
    powershell -ExecutionPolicy Bypass -File scripts\Pull-AppData.ps1 -Serial 2c3f64eb -Package com.valvesoftware.android.steam.community -Prefix steam_phone -IncludeExternal -Stage <stage>
  Emulator (start it with -no-snapshot first):
    powershell -ExecutionPolicy Bypass -File scripts\Pull-AppData.ps1 -Serial emulator-5554 -AdbRoot -Package com.valvesoftware.android.steam.community -Prefix steam_emu -IncludeExternal -Stage <stage>
  Output: collected\<prefix>_<stage>.tar (+ _external.tar) and collected\collection_log.csv.
  The script force-stops Steam; open it again afterwards. MISMATCH -> rerun as <stage>_b.

ANALYSIS CHECKLIST (after both runs)
========================================================================
1. collection_log.csv: every line hashes_match = True.
2. Extract each tar to its own folder:
     New-Item -ItemType Directory work_steam\<prefix>_<stage> -Force
     tar -xf collected\<prefix>_<stage>.tar -C work_steam\<prefix>_<stage>
3. Where does Steam write?  Diffoscope 01_baseline vs 02_after_guard on
   throw-away copies (exclude *-wal, *-shm, *-journal).  List changed files.
4. Current data: sqlite3 / DB Browser on throw-away copies of any SQLite file;
   read shared_prefs\*.xml and any JSON files.
5. Steam Guard data: find the file(s) holding the authenticator (search for
   "shared_secret", "identity_secret", "revocation", "steamguard", the account
   name / SteamID). Record path, format, and whether it is plain text,
   encrypted, or tied to the Android Keystore. Do NOT copy values.
6. Login approvals: search for the A2/A3 times, IP/location text, "approve",
   "deny", "session", "confirmation" - is any record of A2-A4 kept on the DUT?
7. Markers: scripts\Search-RawText.ps1 -Text STEAM01,STEAM03 on every stage.
8. Deleted data: sqlite4n6 audit + carve (-f jsonl) on SQLite files; raw
   pattern search for partial records.
9. JADX on the Steam APK: which files, SharedPreferences and Keystore aliases
   does the app use for the authenticator? (Steam 3.x is mostly React Native:
   check assets\index.android.bundle too.)
10. Findings CSV: time_utc, app, event, source, stage, status, method.

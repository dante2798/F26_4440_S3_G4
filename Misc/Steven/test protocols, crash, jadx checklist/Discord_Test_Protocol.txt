========================================================================
PREPARATION (before any test step)
========================================================================
[v] P1  TWRP backup of the phone is on the PC.
[v] P2  Play Store auto-update OFF for Discord. Phone date/time = automatic.
[v] P3  Push the phone's test image so it is in the gallery BEFORE baseline:
          adb -d push test_media\TEST14_sent.png /sdcard/Pictures/TEST14_sent.png
          adb -d shell am broadcast -a android.intent.action.MEDIA_SCANNER_SCAN_FILE -d file:///sdcard/Pictures/TEST14_sent.png
[v] P4  Root check (approve the Magisk prompt on the phone):
          adb -d shell su -c id            -> must show uid=0(root)
[v] P5  Clean start: Settings > Apps > Discord > Storage > Clear data.
        (Same starting point as the emulator: fresh login, empty cache.)
[v] P6  Log in to Discord on the phone (my account). Open the DM with the
        friend account once, then leave Discord idle for 2 minutes.
[v] P7  Friend account logged in on PC (Chrome incognito), same DM open.

Pull command for every stage (project folder, PowerShell):
    powershell -ExecutionPolicy Bypass -File scripts\Pull-DiscordPhone.ps1 -Stage <stage>
  It force-stops Discord, makes one tar of /data/data/com.discord on the phone,
  hashes it there, pulls it to phone\, hashes it again and logs both in
  phone\collection_log.csv. Re-open Discord after every pull.
  If it shows "MISMATCH", run it again with the stage name + "_b".

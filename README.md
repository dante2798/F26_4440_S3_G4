# F26_4440_S3_G4

## Course information

This repository belongs to Group 4 of Section 3 of CSIS 4440, Mobile Cybersecurity, at Douglas College during the Fall 2026 term. The repository name follows the format required for the course (Term#_4440_S#_G#), so F26 stands for Fall 2026, S3 is our section and G4 is our group number.

## About the project

This is the group project for the course, completed by a team of two students. The project focuses on digital forensics for Android mobile devices. Each team member works on an individual part that includes a forensic tool and the analysis of apps that were not covered in class. The exact tools and apps, along with the forensic scenario, will be described in the project proposal once they are confirmed with the instructor.

## Repository structure

The ReportsAndDocuments folder holds all of the reports, work logs and documentation for the project, including the proposal, the progress report and the final report. The Misc folder is optional and is used for any other files that the team or the project needs, such as scripts, screenshots or notes that do not belong in the reports.
